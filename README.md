# Pure Seduction Registration Landing Page

A responsive registration landing page inspired by the supplied Pure Seduction fragrance materials.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Files

- `index.html` — page structure and registration form
- `styles.css` — responsive visual styling
- `script.js` — registration success-state interaction
- `pure-seduction-collection.png` — primary product image
- `pure-seduction-mist.png` and `pure-seduction-lotion.png` — supporting product assets

The form currently demonstrates the front-end success state. Connect it to a form provider or backend before using it for production submissions.
